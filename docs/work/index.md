# งาน 💼

โน้ตเกี่ยวกับงาน: ขั้นตอนที่ทำบ่อย วิธีแก้ปัญหาที่เคยเจอ และสิ่งที่ต้องจำ

!!! warning "ข้อมูลบริษัท"
    ถ้า repo นี้เป็น public อย่าใส่ข้อมูลภายใน/ความลับของบริษัทลงในโน้ต
    เก็บเฉพาะความรู้ทั่วไปและวิธีการทำงานของตัวเอง

## โน้ตในหมวดนี้

*(ยังไม่มี — เพิ่มโน้ตแรกได้เลย ดู[วิธีเพิ่มโน้ต](../guide/add-note.md))*

## เทมเพลตโน้ตแก้ปัญหา

คัดลอกไปใช้เวลาจดวิธีแก้ปัญหาที่เจอ:

```markdown
# ปัญหา: (อาการที่เจอ)

**วันที่เจอ:** YYYY-MM-DD

## อาการ
สิ่งที่เห็น / ข้อความ error

## สาเหตุ
ต้นตอจริง ๆ ของปัญหา

## วิธีแก้
ขั้นตอนที่ทำแล้วหาย (ละเอียดพอที่ตัวเองในอีก 6 เดือนจะทำตามได้)

## กันไม่ให้เกิดซ้ำ
(ถ้ามี)
```
