## จุดเด่นของคลังนี้

!!! tip "ใช้ได้ทุกที่"
    แก้ไขผ่านเว็บ GitHub จากเครื่องไหนก็ได้ (รวมถึงคอมบริษัท) —
    กด commit แล้วเว็บอัปเดตเองภายใน 1–2 นาที

- **ค้นหาได้** — ช่องค้นหาด้านบนค้นทุกโน้ตพร้อมกัน
- **มีโครงสร้าง** — โฟลเดอร์ = หมวดหมู่ เพิ่มหมวดใหม่ได้ตามใจ
- **ฟรี 100%** — GitHub Pages ไม่มีค่าใช้จ่าย
