# วิธีเพิ่ม/แก้ไขโน้ต

ทุกอย่างทำผ่านเว็บ GitHub ได้เลย ไม่ต้องติดตั้งโปรแกรมใด ๆ

## เพิ่มโน้ตใหม่

1. เข้า repo บน GitHub → โฟลเดอร์ `docs/`
2. เลือกหมวด (เช่น `work/`) → กด **Add file → Create new file**
3. ตั้งชื่อไฟล์ลงท้าย `.md` เช่น `sql-tips.md`
4. เขียนเนื้อหาเป็น Markdown → กด **Commit changes** (commit เข้า `main` ตรง ๆ ได้เลย)
5. รอ 1–2 นาที เว็บจะอัปเดตอัตโนมัติ

!!! note "อยากให้โผล่ในเมนูซ้าย"
    เพิ่มรายการในไฟล์ `mkdocs.yml` ตรงส่วน `nav:` เช่น

    ```yaml
    nav:
      - งาน:
          - work/index.md
          - SQL tips: work/sql-tips.md
    ```

    ถ้าไม่เพิ่มใน `nav` หน้าเว็บก็ยังเข้าถึงได้ผ่านการค้นหาและลิงก์

## แก้ไขโน้ตเดิม

- เปิดหน้านั้นบนเว็บคลังความรู้ → กดไอคอน **ดินสอ** มุมขวาบน
  (ลิงก์ตรงไปหน้าแก้ไขบน GitHub) → แก้ → Commit

## เพิ่มหมวดใหม่

1. สร้างไฟล์ `docs/ชื่อหมวด/index.md`
2. เพิ่มหมวดใน `nav:` ของ `mkdocs.yml`

## Markdown ที่ใช้บ่อย

```markdown
# หัวข้อใหญ่
## หัวข้อรอง

**ตัวหนา** *ตัวเอียง* `โค้ด`

- รายการ
- รายการ

1. ลำดับ
2. ลำดับ

[ลิงก์](https://example.com)

| คอลัมน์ | คอลัมน์ |
|---------|---------|
| ข้อมูล  | ข้อมูล  |
```

### กล่องเน้นข้อความ (admonition)

```markdown
!!! tip "เคล็ดลับ"
    เนื้อหาในกล่อง (ย่อหน้าด้วย 4 เว้นวรรค)

!!! warning "ระวัง"
    ใช้เตือนเรื่องสำคัญ
```

!!! tip "เคล็ดลับ"
    แบบนี้แหละที่มันแสดงผล

## ดูตัวอย่างก่อนเผยแพร่ (ถ้าต้องการ)

เปิด Codespace (ปุ่ม **Code → Codespaces**) แล้วรัน:

```bash
mkdocs serve -a 0.0.0.0:8000
```

จะได้ preview สด ๆ ที่พอร์ต 8000 — แก้ไฟล์แล้วหน้าเว็บรีเฟรชเอง
