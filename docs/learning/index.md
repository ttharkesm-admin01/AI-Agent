# เรียนรู้ 🌱

สิ่งที่กำลังศึกษา สรุปจากคอร์ส/วิดีโอ/บทความ และไอเดียที่อยากลอง

## โน้ตในหมวดนี้

*(ยังไม่มี — เพิ่มโน้ตแรกได้เลย ดู[วิธีเพิ่มโน้ต](../guide/add-note.md))*

## เทมเพลตสรุปสิ่งที่เรียน

```markdown
# เรื่อง: (หัวข้อที่เรียน)

**แหล่งที่มา:** (ลิงก์คอร์ส/วิดีโอ/บทความ)
**สถานะ:** กำลังเรียน / จบแล้ว

## สรุปสั้น ๆ 3 บรรทัด
สิ่งสำคัญที่สุดที่ได้จากเรื่องนี้

## รายละเอียด
จดตามที่เข้าใจ ไม่ต้องเป๊ะ เน้นให้ตัวเองอ่านรู้เรื่อง

## เอาไปใช้ทำอะไรได้
การประยุกต์กับงานหรือชีวิตจริง
```
